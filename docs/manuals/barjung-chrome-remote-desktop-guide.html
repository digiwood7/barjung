Chrome 원격 데스크톱 · 원격 지원
3

지원 받기 아래의 다운로드 버튼을 누르세요

Chrome 웹스토어 또는 설치 안내가 열리면 화면의 추가, 동의 및 설치, 설치 버튼을 순서대로 누릅니다. 내려받은 설치 파일이 보이면 클릭해 실행하세요.

4

Windows 질문 창에서는 예를 누르세요

“이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?”라고 나오면 게시자가 Google인지 확인한 다음 예를 누릅니다.

5

페이지로 돌아가 코드 생성을 누르세요

화면에 표시된 일회용 접속 코드를 전화나 메시지로 지원 담당자에게 알려주세요. Google 비밀번호와 Windows 비밀번호는 알려주지 않습니다.

6

담당자 이메일을 확인하고 공유를 누르세요

지원 담당자의 Google 계정 이메일이 맞는지 확인한 뒤 공유를 허용합니다. 연결 중 관리자 확인 창이 뜨면 고객님이 직접 예를 눌러야 할 수 있습니다.

7

작업이 끝나면 공유 중지를 누르세요

브라우저의 원격지원 페이지에서 공유를 중지하면 즉시 연결이 종료됩니다. 일회용 코드는 다시 사용할 수 없습니다.

고객에게 그대로 읽어주세요

다운로드한 파일이 안 보여요

Chrome 오른쪽 위의 다운로드 화살표를 누르거나 Windows에서 Ctrl + J를 눌러 최근 다운로드 목록을 엽니다.

코드가 만료됐다고 나와요

코드는 일회용입니다. 고객이 원격지원 페이지에서 코드 생성을 다시 눌러 새 코드를 전달합니다.

화면이 멈추거나 너무 느려요

양쪽 PC를 유선랜에 연결하고, 대용량 다운로드와 클라우드 동기화를 잠시 멈춘 뒤 다시 연결합니다.

관리자 확인 창에서 조작이 안 돼요

고객이 Windows PC 앞에서 직접 예를 눌러야 할 수 있습니다. 관리자 암호가 필요하면 고객이 직접 입력합니다.

안전한 원격지원 운영 원칙

  • 접속 코드는 지원 직전에 만들고, 통화 중인 담당자에게만 전달합니다.
  • 고객의 Google·Windows·금융 비밀번호를 요청하거나 저장하지 않습니다.
  • 고객 동의 없이 무인 접속을 설정하지 않습니다.
  • 지원이 끝나면 공유 중지와 세션 종료를 양쪽에서 확인합니다.
